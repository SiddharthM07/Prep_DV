When something happens in AWS:
EventBridge catches it → sends it to the right service.

Code :

Boto3:
1️--> Client  (low-level API)


client = boto3.client("ec2", region_name="us-east-1")
You are directly calling AWS APIs.Raw AWS API calls

Returns dictionaries (JSON-like)
Fast
Complete AWS feature support
Used for listing / describing

2️--> Resource (high-level object-oriented)
ec2_resource = boto3.resource("ec2", region_name="us-east-1")
Now AWS gives you objects, not raw JSON.You work with an object directly.

Steps:
1. Describe volumes
2. Check attachments
3. Store unattached IDs
4. Delete using resource API
