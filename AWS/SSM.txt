SSM --A service to manage and operate servers at scale.
SSM agent  needs to be installed in instances 


To connect to a private EC2 we need VPC endpoints too. VPC Endpoints provide Private network path to AWS services So EC2 can reach SSM privately.
Below are the requierd endpoints:    
com.amazonaws.<region>.ssm
com.amazonaws.<region>.ec2messages
com.amazonaws.<region>.ssmmessages

How does EC2 download patches without NAT?

We can use AWS Systems Manager Patch Manager along with required VPC endpoints like SSM and S3 so the instance can download and apply patches privately without internet access. Another approach is using internal repositories or immutable AMI updates.
