AWS WAF is a web application firewall used to protect applications from common web exploits by inspecting incoming HTTP and HTTPS requests. It works with services like ALB, CloudFront, and API Gateway and uses rule-based filtering to block malicious traffic such as SQL injection, XSS, or abnormal request rates.
