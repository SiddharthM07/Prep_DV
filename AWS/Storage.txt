=====================================================================
A superblock is the brain of the filesystem.

It stores critical information like:

filesystem type (ext4)

size of the filesystem

number of blocks

inode count

free space

mount information

Think of it like:

📘 The master instruction book of your disk partition.

If the superblock gets corrupted, your filesystem becomes unreadable.

✔ That’s why ext4 creates multiple backup superblocks

(so you can recover the filesystem even if the main superblock is damaged)

creating filesystem with 2096896 4k blocks and 524288 inodes
✔ This means:
The filesystem is made of ~2,096,896 blocks

Each block is 4KB

It created 524,288 inodes (each inode = metadata holder for a file)

Superblock backups stored on blocks:
32768, 98304, 163840, ...
✔ These are locations where backup superblocks are written
If your filesystem gets corrupted one day, you can recover using:

bash
Copy code
fsck.ext4 -b 32768 /dev/nvme1n1p1
