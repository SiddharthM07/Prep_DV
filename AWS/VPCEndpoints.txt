ENI = Elastic Network Interface

A virtual network card (NIC) attached to an EC2 instance.
An ENI is a virtual network interface in a VPC that provides networking capability to EC2 instances.

An ENI carries all networking information:
Private IP address
Public IP (optional)
Elastic IP (optional)
Security Groups
MAC address
Subnet

Types of ENI 

-->Primary ENI (eth0)
Created automatically when EC2 launches.
Cannot be detached
Required for instance networking

-->Secondary ENI

You can attach additional ENIs.

Used for:
multiple networks
appliances
advanced routing


An EC2 can have multiple NIC attached for which are in Different subnet and different SG rules

When you think:
IP address
Security group
Subnet
Actually they belong to ENI — not EC2 directly
