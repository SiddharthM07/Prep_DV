It's a jenkins job type that scans SCM and automatically creates a child pipeline for every branch/tag/PR 
I could have 10 branches but I only want some branches to be run for that we will not supply Jenkinsfile over there
Jenkins Sees for Jenkinsfile to run pipeline
Lifecycle :can be created via webhooks or poll or manual 
Lower Blast radius: Isolates builds keep main clean 

Once the branch deletes the branch also retires and auto deleted

pipeline:

runs on push (webhook)----------> 
compile,unit test,lint,coverage
package build container
publish Artifact/metadata(SBOM)
Software Build of Materials
repo of lib to build code 


- Create branch (feature/ui-font)
- Consistent naming: feature/*, bugfix/*
- ⏱ target ≤5m
Push → Branch Job
- Runs on each push (webhook/scan)
- Compile, unit tests, lint, coverage
- Package + build container image; no deploy
- Publish artifact/metadata (SBOM)
- ✏️ needs app running
Open PR → PR job
- Triggers on PR open/update
- Run light SAST + dependency scans (code/manifests)
- Deploy ephemeral preview (namespace/stack per PR)
- Integration/E2E smoke
- Teardown preview on completion/PR close
- 🔒 required checks
Gate the merge on deploy success
- All required checks green, incl. "deploy succeeded"
- Enforce required checks + "up-to-date with base"
- If red → fix, push, re-run PR job
- ♻️ promote artifact
Merge to main
- Main pipeline runs on merge
- Reuse signed artifact/image (or rebuild deterministically)
- Deploy to dev/stage; verify; promote with approvals
- Git host auto-deletes source branch (if enabled)
- Jenkins prunes branch job/workspace (orphan cleanup)












pipeline {
    agent any
    environment {
        IMAGE="docker.io/cloudwithvarjosh/cwvj-flask"
        TAG="${BUILD_NUMBER}"
    }
    stages {
        stage ('build') {
            steps {
                sh 'docker build -t "$IMAGE:$TAG" -t "$IMAGE:latest" .'
            }
        }
        stage ('push') {
            steps {
                withCredentials([usernamePassword(credentialsId: 'dockerhub', passwordVariable: 'DOCKERHUB_PWD', usernameVariable: 'DOCKERHUB_USER')]) {
                sh 'echo "$DOCKERHUB_PWD" | docker login -u "$DOCKERHUB_USER" --password-stdin'
                sh 'docker push "$IMAGE:$TAG"'
                sh 'docker push "$IMAGE:latest"'
}
                
            }
        }
stage('deploy') {
      steps {
        sh 'docker pull "$IMAGE:$TAG"'
        sh 'docker rm -f cwvj-flask || true'
        sh 'docker run -d --name cwvj-flask -p 5000:5000 "$IMAGE:$TAG"'

        // write deploy info with build number in the filename
        sh '''
          cat > deploy-info-$BUILD_NUMBER.txt <<EOF
build: $BUILD_NUMBER
image: $IMAGE:$TAG
commit: ${GIT_COMMIT}
branch: $GIT_BRANCH
time: $(date -u +"%Y-%m-%dT%H:%M:%SZ")
url: $BUILD_URL
EOF
        '''

        // fingerprint: true tells Jenkins to compute and store a unique hash (a “fingerprint”) for the archived file.
        archiveArtifacts artifacts: "deploy-info-${BUILD_NUMBER}.txt", fingerprint: true, followSymlinks: false
      }
    }
        stage ('test') {
            steps {
                sh 'sleep 2; echo "Hit http://localhost:5000 to see the app."'
            }
        }      
            stage ('cleanup') {
            steps {
                cleanWs()
            }
        }
    }
      post {
    success {
        echo "Build ${env.BUILD_NUMBER} succeeded"
        }
    failure { echo "Build ${env.BUILD_NUMBER} failed" }
    always  { echo "Build ${env.BUILD_NUMBER} finished" }
  }
}
