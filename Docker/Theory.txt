Common Layer-Creating Instructions
In Docker, each instruction in a Dockerfile creates a new image layer (except for FROM, which sets the base image, and some metadata instructions like LABEL that may be merged).


- RUN → Executes commands and stores the resulting filesystem changes.
- COPY / ADD → Copies files into the image, creating a new layer.
- CMD / ENTRYPOINT → Defines default commands; these also form layers.
- ENV / WORKDIR / EXPOSE / USER → Configuration changes are stored as layers.
Key Notes
- Layers are immutable and cached: if nothing changes in a step, Docker reuses the cached layer.
- Optimizing Dockerfiles often means ordering instructions so that frequently changing steps (like COPY .) come later, avoiding unnecessary rebuilds.
- The final image is a stack of these layers, combined into a single filesystem view.
